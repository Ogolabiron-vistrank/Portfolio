# Biron Ogola Portfolio

Personal portfolio website built with HTML, CSS and JavaScript.

Live site: https://biron-portfolio.vercel.app/

## Sections
Home, About, Skills, Insights (charts), Education, Experience, Projects, Contact

## JavaScript features
- Dark mode toggle, saved with localStorage
- Mobile menu toggle
- Rotating role text
- Animated counters and charts
- Scroll reveal animations
- Back to top button

## Built with
HTML5, CSS3, JavaScript, Git, GitHub, Vercel

## Run locally
Open index.html in a browser, or use the Live Server extension in VS Code.
